Политика конфиденциальности Vacancier

Последнее обновление: 12 ноября 2026 г.

1. Общая информация

Настоящая Политика конфиденциальности описывает, какие персональные данные собирает и обрабатывает сервис Vacancier, для каких целей используются эти данные, а также какие права есть у пользователей.

Оператор сервиса осуществляет свою деятельность из Республики Сербия.

Используя Vacancier, пользователь подтверждает, что он ознакомился с настоящей Политикой конфиденциальности и понял ее содержание.

2. Данные, которые мы собираем

При использовании сервиса могут обрабатываться следующие категории данных:

2.1. Данные из Telegram

  • идентификатор пользователя в Telegram (User ID);
  • имя пользователя (username) — при наличии;
  • имя и другая информация профиля, предоставляемая Telegram;
  • техническая информация, необходимая для функционирования бота.

2.2. Данные о предпочтениях пользователя

  • ключевые слова для поиска вакансий;
  • настройки фильтров;
  • предпочтения относительно должностей и технологий;
  • история найденных и отправленных пользователю вакансий.

2.3. Резюме и результаты их анализа

Если пользователь загружает резюме, могут обрабатываться следующие данные:

  • текст резюме;
  • профессиональный опыт;
  • навыки и технологии;
  • образование;
  • владение языками;
  • желаемая должность;
  • результаты автоматизированного анализа;
  • результаты сопоставления резюме с вакансиями.

Пользователям рекомендуется не включать в резюме информацию, которая не требуется для поиска работы.

2.4. Платежные данные

При использовании платных функций могут обрабатываться следующие данные:

  • сведения о тарифном плане (подписке);
  • статус подписки;
  • количество оплаченных «звезд» Telegram (Telegram Stars);
  • идентификаторы платежных транзакций;
  • даты начала и окончания подписки;
  • информация о возврате средств. Vacancier не получает и не хранит данные банковских карт пользователей при оплате через Telegram Stars.

3. Цели обработки данных

Персональные данные используются для следующих целей:

  • идентификация пользователя;
  • предоставление доступа к функциям бота;
  • сохранение заданных пользователем фильтров;
  • поиск и подбор вакансий;
  • отправка уведомлений;
  • автоматизированный анализ резюме. - сопоставление резюме с требованиями вакансий;
  • управление подписками и платежами;
  • предоставление технической поддержки;
  • обеспечение безопасности Сервиса;
  • соблюдение требований законодательства.

Данные не используются для продажи профилей пользователей или передачи резюме работодателям в рекламных целях.

4. Использование API OpenAI

Vacancier использует API OpenAI для автоматизированного анализа резюме и их сопоставления с вакансиями.

В рамках этого процесса текст резюме (или его соответствующие части) может быть передан в OpenAI.

OpenAI обрабатывает переданные данные в соответствии со своими собственными условиями и применимыми соглашениями об обработке данных.

Согласно стандартным условиям использования API OpenAI, данные, передаваемые через API, по умолчанию не используются для обучения моделей; однако могут применяться механизмы ограниченного хранения данных в целях обеспечения безопасности и предотвращения злоупотреблений.

Пользователям следует учитывать, что обработка данных может осуществляться за пределами страны их проживания.

Vacancier не передает OpenAI идентификатор пользователя (Telegram User ID) или имя пользователя (username), за исключением случаев, когда это необходимо для выполнения конкретной операции.

5. Правовые основания для обработки

Персональные данные обрабатываются на основаниях, предусмотренных действующим законодательством, в том числе:

  • исполнение договора и предоставление функций, запрошенных пользователем;
  • согласие пользователя (в случаях, когда оно требуется);
  • законные интересы оператора данных (например, обеспечение безопасности и предотвращение злоупотреблений);
  • соблюдение юридических обязательств.

Если обработка осуществляется на основании согласия, пользователь может отозвать его в любой момент. Отзыв согласия не влияет на законность обработки, которая была проведена до момента такого отзыва.

6. Передача данных третьим лицам

Для обеспечения своей деятельности Vacancier может привлекать сторонних поставщиков услуг, включая:

  • Telegram — предоставление инфраструктуры для работы бота и механизмов оплаты;
  • OpenAI — автоматизированный анализ текста резюме;
  • провайдеров серверной инфраструктуры и хостинга;
  • других поставщиков технических услуг, необходимых для функционирования Сервиса.

Данные передаются только в том объеме, который необходим для достижения конкретных целей обработки.

Vacancier не продает персональные данные пользователей третьим лицам.

7. Трансграничная передача данных

Поскольку компания Vacancier осуществляет свою деятельность из Республики Сербия и использует международные технические сервисы, персональные данные могут передаваться в другие страны и обрабатываться на их территории.

Такая передача осуществляется в соответствии с требованиями применимого законодательства о защите данных.

При необходимости применяются предусмотренные законом меры по обеспечению защиты данных при их трансграничной передаче.

7. Международная передача данных

Поскольку Vacancier осуществляет свою деятельность из Республики Сербия и использует международные технические сервисы, персональные данные могут передаваться в другие страны и обрабатываться в них.

Такая передача осуществляется в соответствии с требованиями применимого законодательства о защите персональных данных.

При необходимости применяются правовые механизмы, обеспечивающие защиту данных при их трансграничной передаче.

8. Сроки хранения данных

Персональные данные хранятся только в течение того времени, которое необходимо для достижения целей, для которых они были собраны.

В частности:

Данные из Telegram и настройки пользователя — в течение всего периода использования пользователем Сервиса;

Резюме — в течение периода, необходимого для предоставления функций анализа;

Результаты подбора вакансий — в течение времени, необходимого для функционирования Сервиса, или до момента получения запроса на их удаление;

Платежные данные — в течение периода, необходимого для учета платежей и выполнения юридических обязательств;

Технические логи — в течение периода, необходимого для обеспечения безопасности и проведения диагностики.

Определенные данные могут храниться в течение более длительного срока, если этого требует законодательство.

9. Удаление данных

Пользователи могут запросить удаление своих персональных данных, воспользовавшись функциями, доступными в боте, или обратившись в службу поддержки.

После получения такого запроса оператор удалит данные, при условии отсутствия правовых оснований для их дальнейшего хранения.

Удалению могут подлежать:

Резюме;

Текст, извлеченный из резюме;

Результаты анализа, выполненного с использованием ИИ;

Настройки пользователя;

История подбора вакансий.

Данные, подлежащие хранению в соответствии с применимым законодательством, могут сохраняться в течение срока, установленного законом.

В зависимости от применимого законодательства, пользователь может иметь право:

Получать информацию об обработке своих персональных данных; получать копию своих персональных данных;

Требовать исправления неточных данных;

Требовать удаления данных;

Ограничивать обработку данных;

Возражать против обработки данных;

Получать свои данные в переносимом формате; отзывать согласие;

Подавать жалобу в компетентный надзорный орган.

Для реализации своих прав пользователи могут обратиться к оператору Сервиса. 11. Безопасность данных

Оператор принимает технические и организационные меры для защиты персональных данных от несанкционированного доступа, изменения, утраты или разглашения.

К числу таких мер могут относиться:

ограничение доступа к данным;

использование защищенных соединений;

защита серверной инфраструктуры;

создание резервных копий данных;

контроль доступа к резюме и пользовательским данным.

Несмотря на принимаемые меры, абсолютная безопасность передачи и хранения информации не может быть гарантирована.

12. Данные несовершеннолетних

Сервис Vacancier предназначен для пользователей, достигших 18 лет.

Оператор намеренно не собирает персональные данные несовершеннолетних.

Если оператору станет известно, что были предоставлены данные несовершеннолетнего лица без надлежащего правового основания, оператор предпримет необходимые меры для урегулирования ситуации.

13. Изменения Политики конфиденциальности

Оператор может время от времени обновлять настоящую Политику.

Актуальная версия всегда доступна по команде /privacy.

В случае внесения существенных изменений пользователи могут получить соответствующее уведомление.
